# Text-Typer-with-code-detection

Detects all major programming languages and applies syntax highlighting based on the detected language.

You will need to install the required packages.

Python 3.15 was used for this project.

(Packages should install automatically. If they do not, you will need to install them manually:)
• pynput>=1.7.7
• pygments
